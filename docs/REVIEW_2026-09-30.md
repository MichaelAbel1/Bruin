### 指标与副作用

- 元数据读取从无界改为最多 1 MB，文本字段继续遵循导入端的 60,000 字符上限；FIFO 拒绝无需等待写入端。损坏、错配或不符合当前导入格式的旧手工记录会被拒绝。
- 畸形 OAuth 请求从未捕获异常改为 HTTP 400，不消耗有效登录回调。
- 会话所有权不确定时取消运行，不再让定时器异常直接崩溃。暂时性数据库故障也可能提前取消当前回合；未知副作用仍按原恢复机制人工复核。
- Git 基线查询有 5 秒上限；慢于该上限的正常 Git 查询也会省略基线。同步查询在此上限内仍会阻塞后台，异步化尚未实施。
- 子 Agent 每 10 秒续期、30 秒租约过期，沿用主会话参数，增加少量 SQLite 更新。未变更公共工具参数、事件类型、数据库结构、依赖或构建配置。
- 第六轮后父会话租约持续到所有关联工作结算，因此后台任务运行期间不能删除、跨进程恢复或用另一所有者修改会话；同进程的新前台回合仍可开始。心跳仍为每 10 秒续期 30 秒租约，未改变 EventStore 接口、schema 或工具协议。
- 第七轮后取消可以中断 CLI 输入等待；正常输入、批准/拒绝及恢复确认格式保持兼容。取消仍按 CLI 现有错误出口返回状态码 1。
- 本轮没有性能负载测试，不声称吞吐、内存或延迟已有整体改善。
